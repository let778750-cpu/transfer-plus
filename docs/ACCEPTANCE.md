## 0.3.6 一次点击的正文补全与 PDF 合成（2026-11-12）

旧存档重复点击仍显示约 68% 的主要原因是原生文字被拆成大量短片段、同一公式字形被重复归属，以及局部排版把段落边缘和整块算法框误判为不可写。新版本以云端结构归并完整自然段，每个原生字形只归属一次；一般斜体词、标题、正文按自然语言处理，算法中的数学对象原位保留、自然语言按行处理。旧 inventory 升级为 schema 6；合成规则与最终 PDF 缓存同步换代，旧译文继续复用。两种入口均走同一自动检查和交付流程，继续更新同一中文附件，不加入补译面板。

PDF 合成改为逐页暂存所有中文片段，先删除原文字，再放入中文和原公式片段，避免后续 redaction 损坏先前片段共享的 Form XObject。原公式路径不做整页图形删除，旧位置只覆盖已核对的局部；覆盖框遇到图片或非所属线条时拒绝该局部。普通背景、分式根号、邻近表格线、彩色底图和图例色块均有针对性回归。单行区域不使用正文的大留白，候选区域允许利用实际相邻空白并核验其他字形；不以删除公式或隐藏未完成项提高比例。

127 项 Python 检查、40 项 Node 检查通过。三轮独立评审的任务 Token、正文绑定和产物 SHA256 已核验；评审发现的作者行误判、数学路径删除和白底覆盖其他图形问题均修复并补充回归。最后一轮覆盖边界与短标签重试修复由主代理复核，不声称修改后的全部代码已经独立复审。空 OCR 结果会重新解析对应批次，翻译失败可重试；相同规则下已尝试的结构性排版限制不会反复生成相同文件，但仍明确报告未完成数量。图中短标签连续两次取得成功响应、但模型均原样返回时，标记为 unresolved_ocr_label 并保留在未完成清单，避免把变量或 OCR 碎片当成必须译成中文的词反复请求；网络失败和普通段落仍可重试。
