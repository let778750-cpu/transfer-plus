# BabelDOC 0.7.1 适配

实现位于 `server/rmb/engine_patch.py`，通过进程内适配固定版本的公开 Python/Rust 入口；不改写已安装引擎文件。

- 普通 Times/Nimbus 等斜体中的变量基字在上游默认判断中可能被当作正文。适配将 italic/oblique 字体原字形纳入数学保护，其他字体仍使用原规则；明确传入字体模式，使 Rust 桥接调用 Python 判断入口。
- 0.7.1 的发行 wheel 未启用阶段捕获开关。清洁输出的 `MDocument.artifact()` 在 writer 完成后导出最终 IR，并用上游序列化器保存。质量检查绑定这个实际最终布局及交付候选 PDF 哈希，不把带调试标记的 PDF 当作交付结果。
- 调试解析提供源数学字形清单。跨两次解析使用稳定的原绘制顺序匹配段落；随机 debug ID 不作为跨次身份。
- 使用同步 `do_translate` 与 ProgressMonitor，规避异步完成通知与空队列等待的竞态。每个任务运行在独立子进程，取消时关闭所属 Windows Job Object。

公式检查涵盖字形、字码、字体、相对位置、相对字号和对象宽高。多行公式组、未完整保护的斜体片段、占位符损坏及安全排版失败会触发原段/整页回退。保护只能发现明确覆盖的错误，不能证明任意 PDF 全部正确。

`upstream/` 保存对应 v0.7.1 的源码用于审查，实际运行版本由 requirements.lock 固定。升级引擎时必须重新检查上述入口和真实数学版式。
